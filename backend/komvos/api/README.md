# komvos/api

**Owner: P2 — Endpoints & API**

## Purpose

FastAPI application that exposes the execution engine to the Electron desktop
shell over local HTTP and WebSocket. **Bound to `127.0.0.1` only.**

## Routes (R0 plan)

| Method | Path | Description |
| :--- | :--- | :--- |
| `GET` | `/health` | Liveness probe used by Electron after spawning the process. |
| `POST` | `/pipelines/run` | Accept pipeline JSON (schema v2), validate, enqueue run, return `run_id`. |
| `GET` | `/models` | Fetch live model lists from all configured providers (no hardcoded lists). |
| `WebSocket` | `/ws/run/{run_id}` | Stream per-node status, token chunks, token counts, cost, and timing. |
| `POST` | `/runs/{run_id}/stop` | Kill-switch: halt the named run immediately; returns partial trace. |

## Security

- Bound to `127.0.0.1` — **never** `0.0.0.0`.
- Every request must include the **per-session auth token** generated by
  Electron at backend spawn time (passed via `Authorization: Bearer <token>`
  header or a custom header — design decision for Phase 2).
- WebSocket connections are authenticated on the initial handshake.

## Phase (roadmap.md)

- **Phase 2:** All routes above, WebSocket streaming, budget enforcement.
- **Phase 3:** Stop endpoint wired to scheduler kill-switch.
- **Phase 4:** Dynamic model list from providers + Ollama.
